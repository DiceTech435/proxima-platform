# 🌍 Proxima

Proxima is a **location-based marketplace** that connects people to services and products around the globe — from tailoring, carpentry, and barbing to local sellers and beyond.  

🚀 The goal: make it simple to **find, trust, and pay** for everyday services based on your location.  
🔐 Future roadmap: integrate **Web3 technologies** for decentralized identity, escrow payments, and tokenized rewards.  

---

## ✨ Features (MVP)
- 🔎 **Location-based search** for service providers
- 🛠️ **Service categories** (tailoring, carpentry, barbing, sales, etc.)
- 💬 **Provider profiles** with details, pricing, and reviews
- 💳 **Secure payments** (Paystack/Stripe integration first)
- ⭐ **Ratings & reviews** to build trust
- 📍 **Geo-targeted discovery** (nearest providers first)

---

## 🛣️ Roadmap
- ✅ MVP with PHP backend + MySQL
- ✅ REST API for mobile/web clients
- 🔜 User-to-user chat & notifications
- 🔜 Escrow payments
- 🔜 Web3 integration (DID, smart contracts, tokenized rewards)

---

## 🛠️ Tech Stack
- **Backend:** PHP (OOP), MySQL  
- **Frontend:** React.js (future), Tailwind CSS  
- **APIs:** Paystack (payments), Google Maps API (location services)  
- **Security:** OWASP best practices (input sanitization, escaping, CSRF protection)
